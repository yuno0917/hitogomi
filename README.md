# この中にニンゲンがいる（仮）

みんなで遊ぶブラウザのパーティーゲームの試作です。

PCの画面に、同じ見た目の人が40人ほど歩いています。その中に、スマホで操作しているプレイヤー（ニンゲン）がまぎれています。

- **ニンゲン**：まわりの人と同じように歩いて、★を集めます。集めきったら勝ちです。
- **★**：広場にはニンゲンの数だけ★があります。NPCもまちがって★を取ることがあり、そのときは数に入らず、別の場所に新しい★が出ます。見た目と音は同じなので、鬼にはだれが取ったかわかりません。集まった数はニンゲンのスマホにだけ出て、PCの画面では終わるまで「？」です。
- **鬼**：赤い鬼のキャラで広場を歩き、動きのあやしい人をつかまえます。ニンゲンを全員つかまえるか、時間切れまで★を集めさせなければ勝ちです。ハズレは3回までです。
  - 「つかまえる！」ボタン（PCはスペース）：目の前の人をつかまえる前方攻撃。
  - タップ（PCはクリック）：画面で人をタップしてつかまえる。鬼のまわりの点線の輪の中の人だけで、輪の外の人には「とどかない」と出ます。
  - 鬼はふつうの人より少し速く歩けます。自分さがしタイムのあいだは動けません。
- **残機（チームで共有）**：ニンゲンがつかまると、チームの残機を1つ使って、広場のどこかのNPCにのりうつって遊びつづけます。のりうつる先は、なるべく鬼から遠いNPCです。どれになったかは、スティックを少し動かして自分でさがします。集めた★の数は引きつぎます。
  - 残機がないときにつかまると脱落で、そこから観戦になります。全員が脱落したら鬼の勝ちです。
  - つかまった体は、その場で止まって、プレイヤーの色と名前が出ます。
- 最初の10秒は「自分さがしタイム」です。このあいだ鬼は目をつぶり、ニンゲンはスティックを少し動かして、自分がどれかを見つけます。

## 遊び方（ネットで）

1. PCで https://yuno-lab.com/hitogomi/ を開きます。
2. スマホでPCの画面のQRコードを読みとり、なまえを入れて「参加する」を押します。同じWi-Fiでなくても入れます。
3. PCで鬼を選んで「スタート」を押します。

通信には、無料の PeerJS のサーバーを使います（スマホとPCが最初につながるときと、直接つながれないときの中継）。なまえは部屋の中で表示するだけで、どこにも保存しません（次に入力しなくてすむよう、そのスマホのブラウザにだけ残ります）。

## 遊び方（家で、ネットに置いたものを使わずに）

1. `play.bat` をダブルクリックします。ブラウザでPC用の画面が開きます。
   - 初めてのとき、Windowsの「アクセスを許可する」画面が出たら、「プライベートネットワーク」で許可してください。許可しないとスマホから入れません。
2. スマホをPCと**同じWi-Fi**につなぎ、PCの画面のQRコードを読みとります。
3. なまえを入れて「参加する」を押します。
4. PCで鬼を選んで「スタート」を押します。
   - **このPC**：PCの前の人が、キーボードとマウスで鬼をやります。
   - **ランダム／名前**：スマホの人が鬼をやります。
5. 終わるときは、黒い画面を閉じます。

ロビーでは、次の設定を選べます。選んだ値は次に開いたときも残ります。
- NPCの数（10〜100人）
- 制限時間（1〜5分）
- 集める★の数（ニンゲン1人あたり1〜5個）
- ボットの人数
- 鬼の速さ（おそい・ふつう・はやい・とてもはやい）
- ニンゲンの残機（チームで共有。なし・1・2・3・5・10）
- つかまえられる範囲（せまい・ふつう・ひろい・とてもひろい。前方攻撃とタップの両方が変わります）

スマホにもPCと同じ広場が映ります（右上の「画面をかくす」で消せます）。横向きにすると、左に画面、右に操作が並びます。
- 鬼のスマホには、自分さがしタイムのあいだ広場が映りません。
- PCで鬼をやるときは、WASDか矢印キーで歩き、スペースで前方攻撃、クリックで近くの人をつかまえます。

PCとスマホのほかに、インターネットにつながっている必要があります。スマホとPCが最初につながるときに、無料の PeerJS のサーバーを使うためです。つながったあとのやりとりは、スマホとPCのあいだで直接行います。

## ひとりで試すとき

- 「ボットのニンゲン」を1〜4人にして、鬼を「このPC」にすると、ひとりで鬼をやれます。ボットは、★があればまっすぐ★に向かいます（練習・確認用）。
- PCでもう1つブラウザのウィンドウを開き、QRコードの下のアドレスを開くと、そのウィンドウがコントローラーになります。WASDか矢印キーで歩き、スペースでつかまえます。
- アドレスの最後に `?debug` をつけると、ニンゲンの頭の上に赤い点が出ます（確認用）。`?hide=3` で自分さがしタイムを短くできます。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` / `js/host.js` / `css/host.css` | PCの画面。部屋を立て、ゲームを動かし、スマホに様子を送ります |
| `play.html` / `js/play.js` / `css/play.css` | スマホのコントローラー |
| `js/game.js` | ルールと人の動き（画面や通信には触れません） |
| `js/draw.js` | 広場と人の描画 |
| `js/sound.js` | 効果音（その場で作る音） |
| `tests.html` | ルールのテスト（ブラウザで開くと結果が出ます） |
| `serve.py` / `play.bat` | 同じWi-Fiのスマホから入れるようにする小さなサーバー |

数字（人数、歩く速さ、時間、★の数など）は `js/game.js` の最初の `CONST` にまとまっています。

## できないこと（今の試作）

- 配信の視聴者みんなで鬼をやる遊び方は、まだありません（何百人もつなぐには、専用のサーバーが必要）。
- 回線によっては、スマホがつながらないことがあります。そのときは、PCと同じWi-Fiにつないでください。
- 部屋は最大8人です。
- PCのタブを裏に回すと、ゲームが止まります。
